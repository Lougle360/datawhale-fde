# T-02 干系人分层对齐表

老板 / 中层 / 一线 / HR / IT 各要什么、怕什么。会前单聊，会上只确认，边界写字。

**挂载**：1.1、2.5、5.4。人做、agent 备料：出访谈提纲、会前话术、对齐表。

## 何时用

- 进场第一周列人。
- 多部门确认优先级（2.5）。
- 组织配套、KPI 调整（5.4）。

## 需要的输入

组织架构、项目发起人。没有就先问发起人要。

## 步骤

1. 分层列人：老板 / 中层 / 一线 / HR / IT / 外部合作方。
2. 每人一行：角色、目标、顾虑、影响力、拍板权。
3. 生成会前单聊提纲（顾虑单独化解，不进大会）。
4. 会上只确认与投票。
5. 写边界：谁投入、成功标准、出错谁判。
6. 找到执行一号位：能协调各部门、知道谁掌握什么（NO.4）。找不到则 1.1 未完成，项目不往下开。

## 输出

按 [templates/stakeholder-map.md](templates/stakeholder-map.md) 写到 `01-diagnose/stakeholders.md`。2.5 边界追加到 `02-define/alignment.md`。5.4 回看更新同一张表。

## 完成标准

- 老板、中层、一线三层都有人。
- 执行一号位已点名，或明确「尚未找到」。
- 会前 / 会上动作分开写。

## 常见误判

- 只听老板。
- 把大会当访谈。
- IT 被写成牵头却没标风险（NO.14、NO.20）。
